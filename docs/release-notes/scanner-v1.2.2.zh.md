# OfflineQRScanner v1.2.2

> 仅识别精简版(Windows)。完全离线,不上传任何数据。

## 新增

- 屏幕选区遮罩支持**右键一键取消**(左键拖拽选区不受影响);遮罩底部新增操作提示条(左键拖拽选区 · 右键取消 · Esc 取消)
- 识别结果文本块:点击位置显示闪烁光标,可拖选部分文本、Ctrl+A 按块全选,复制更顺手

## 修复

- **混合 DPI 多屏**下遮罩窗尺寸错位:主屏 2K@150% 时,副屏遮罩被放大 1.5 倍并遮挡邻屏——遮罩窗几何改用物理像素落位,缩放比不再参与窗口定位
- 主窗**最小化**时发起选区,识别完成后主窗不弹出——现在无论成功失败都会还原 + 置前(Alt+W 显隐同步修正)
- 长文本展开后卡片高度不回落(收起时缩略图尺寸未同步)——缩略图改固定 64×64,与卡片高度解耦
- 长文本默认全展开(编辑宿主强制 pre 格式)——默认恢复单行省略,点击展开改为封顶 220px 滚动

## 优化

- 触发屏幕选区到遮罩弹出的耗时:**实测 1080p×2 从 ~1.7s 压缩到 ~0.4s**——PNG 编码换快速压缩、截屏与遮罩窗创建并行执行、原始 RGBA 经二进制 IPC 直传(免 base64/JSON/PNG 解码)
- 选区启动失败自动回滚:关闭已创建的遮罩窗并恢复主窗

## 升级说明

- 覆盖安装,或解压绿色版覆盖旧 exe
- 应用数据目录独立(`com.offlineqr.scanner`),与全功能版 OfflineQR 互不影响
