# OfflineQRScanner v1.2.3

> 仅识别精简版(Windows)。完全离线,不上传任何数据。

## 新增

- **全局快捷键就地修改**:点击工具条上的「选区 Alt+Q」「显隐 Alt+W」徽章,直接按下新组合键即生效(需含 Ctrl/Alt),Esc 取消,配置自动保存;录制期间会临时挂起全局热键,重录与当前相同的组合键也不会误触发屏幕选区
- **帮助浮层**:右上角「?」圆钮显示当前版本与离线说明,可一键前往 GitHub「最新版本下载页」与「项目主页」(经系统浏览器打开,应用本身仍零网络请求)

## 修复

- 快捷键**录制后不生效**:注册与触发匹配两侧的按键字符串格式不同源(如 `alt+q` 与 `alt+KeyQ`),现已统一为同一规范形式——修改快捷键后立即按新组合键即可触发
- 快捷键徽章**录制完成后呼吸闪烁动画不停**:录制结束、Esc 取消、切换窗口后均会正常复位

## 优化

- 顶栏视觉更协调:问号按钮改为主题色圆钮(黑绿/黑黄随主题),配色按钮以**色块**直观呈现当前主题,移除与帮助浮层重复的"离线 · 本地运行"文案
- Release 版窗口标题仅显示「极简二维码 + 版本号」,构建时间等排障标记只保留在 debug 测试版

## 升级说明

- 覆盖安装,或解压绿色版覆盖旧 exe
- 应用数据目录独立(`com.offlineqr.scanner`),与全功能版 OfflineQR 互不影响
