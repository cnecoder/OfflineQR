# OfflineQRScanner v1.2.1

> 仅识别精简版(Windows)。完全离线,不上传任何数据。

## 新增

- 全新应用图标:黑白灰银「定位角」方案,安装包 / 任务栏 / favicon 全套同步
- 屏幕选区遮罩支持**右键一键取消**(左键拖拽选区不受影响);遮罩底部新增操作提示条(左键拖拽选区 · 右键取消 · Esc 取消)

## 修复

- **混合 DPI 多屏**下遮罩窗尺寸错位:主屏 2K@150% 时,副屏遮罩被放大 1.5 倍并遮挡邻屏——遮罩窗几何改用物理像素落位,缩放比不再参与窗口定位

## 优化

- 触发屏幕选区到遮罩弹出的耗时:PNG 编码换用快速压缩(默认压缩在 1080p 上约 1.1s);截屏与遮罩窗创建并行执行;遮罩窗就绪即取图
- 选区启动失败自动回滚:关闭已创建的遮罩窗并恢复主窗

## 升级说明

- 覆盖安装,或解压绿色版覆盖旧 exe
- 应用数据目录独立(`com.offlineqr.scanner`),与全功能版 OfflineQR 互不影响
